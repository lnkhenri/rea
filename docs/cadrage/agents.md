# Agents

On les **nomme** ici. On ne les construit pas tant que l’étape correspondante n’est pas ouverte.

Trois agents, une mission chacun.

| Agent | Mission | Ne fait pas |
|---|---|---|
| **Collecteur** | Ramener des offres selon les critères | Choisir à ta place |
| **Trieur** | Comparer offre et candidat, expliquer le match | Postuler |
| **Rédacteur** | Brouillon de lettre ou de message | Envoyer |

Toi : les critères, le oui/non sur une offre, l’envoi, la relance.

Rien n’est envoyé sans validation humaine.
