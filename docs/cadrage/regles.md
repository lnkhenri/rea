# Règles

## Public / privé

Le GitHub public contient le **système** et des **exemples fictifs**.

Tes CV, offres réelles, lettres, emails restent **privés**.

Les agents s’appuient sur un **modèle** (champs du profil, champs d’une offre), pas sur tes fichiers perso.

Les secrets (clés API, identifiants) : coffre à part, jamais dans le repo ni dans des notes trop largement partagées.

## Deux cadences

- **Job** — traiter des offres, postuler, relancer.
- **Build** — faire avancer REA.

Ne pas les mélanger dans la même liste sans les distinguer.

## Hors scope pour l’instant

Candidature automatique, multi-utilisateurs, mobile, IHM soignée, beaucoup de sources d’offres.
