# Espaces

Quatre espaces. L’IHM vient plus tard.

| Espace | Publié ? | Rôle |
|---|---|---|
| **Candidat** | Non | Parcours, compétences, préférences, contraintes, versions de CV |
| **Offres** | Données non, logique oui | Critères de recherche, collecte, inbox, matching, rejets |
| **Candidatures** | Non | Fiches, lettres, statuts, relances, notes d’entretien |
| **Agents** | Oui | Missions, limites, enchaînement — c’est la vitrine |

**Offres ≠ Candidatures.** Une offre n’est pas un dossier. Une fiche se crée seulement quand on décide d’agir.

## Flux

```
Candidat + critères → collecte → inbox d’offres → matching
                                              ↓
                                        décision humaine
                                              ↓
                                        fiche candidature
                                              ↓
                                      lettre / suivi / relance
```

## Contenu attendu

**Candidat** — qui tu es et ce que tu veux (lieu, remote, contrat, salaire, exclusions, disponibilité). Les fichiers existent déjà à côté du projet ; voir [sources-profil.md](sources-profil.md). On ne les recopie pas ici.

**Offres** — recherches, offres trouvées, pourquoi ça colle ou non, ce qu’on écarte et pourquoi.

**Candidatures** — entreprise, poste, offre liée, statut, pièces, relances.

**Agents** — voir [agents.md](agents.md).
